Customizing Oh My Posh

A step-by-step guide to replacing the displayed username with a unicorn emoji in the macOS Zsh terminal prompt.

Overview

This report documents the customization of Oh My Posh on macOS using the Zsh shell. The objective is to replace the username normally displayed in the terminal prompt with a unicorn emoji.

The customization uses the Oh My Posh JSON configuration file. A username mapping is added to the configuration, and the session segment is configured to display the mapped username.

Project objective

Replace the displayed macOS username with 🦄 while retaining the rest of the terminal prompt.

Commands and Explanations

1. Check the Oh My Posh version

oh-my-posh version

Displays the installed Oh My Posh version. This helps confirm which version is being used before editing the configuration.

Reported version: 31.9.1.

2. Check the current shell

echo "$SHELL"

Displays the user's configured login shell. The expected path for Zsh on macOS is commonly /bin/zsh.

3. Locate the Oh My Posh initialization command

grep -n 'oh-my-posh init' ~/.zshrc

Searches the Zsh configuration file for an existing Oh My Posh initialization command. This identifies the line that may need to be updated.

4. Export the configuration

oh-my-posh config export --output ~/mytheme.omp.json

Exports an Oh My Posh configuration to a JSON file in the user's home directory.

If you are starting from a particular existing custom theme, specify that configuration as the export source using the appropriate --config option.

5. Check the exported file

ls -lh ~/mytheme.omp.json

Lists the configuration file and displays its file size and other details.

6. Create a backup

cp ~/mytheme.omp.json ~/mytheme.omp.json.bak

Creates a backup before making any changes. This allows the original configuration to be restored if the customization causes problems.

7. Open the configuration file

nano ~/mytheme.omp.json

Opens the JSON configuration in Nano so that the username mapping and session segment can be edited.

8. Identify the exact macOS username

whoami

Displays the current account username. Use the exact output as the key in the username mapping.

9. Validate the JSON configuration

python3 -m json.tool ~/mytheme.omp.json > /dev/null && echo "JSON is valid"

Checks whether the configuration file contains valid JSON syntax.

If the JSON is invalid, Python reports a parsing error that can help identify the problem.

10. Reload the Zsh configuration

source ~/.zshrc

Reloads the Zsh configuration so that the updated Oh My Posh initialization command and theme configuration can take effect.

Configuration Changes

1. Add the username mapping

Add a top-level maps property to the Oh My Posh JSON configuration. It should be placed alongside other top-level properties such as palette and blocks, not inside the palette. 

"maps": {
    "user_name": {
        "YOUR_MAC_USERNAME": "🦄"
    }
},
Important

Replace YOUR_MAC_USERNAME with the exact username returned by the whoami command. Do not leave the placeholder in the final configuration.

2. Configure the session segment

The session segment should use the mapped username as its displayed template value. 

{
    "type": "session",
    "style": "plain",
    "template": "{{ .UserName }}"
}

This is an illustrative segment configuration. Integrate it into the appropriate location in the existing theme's block and segment structure, preserving the surrounding JSON syntax.

3. Save the configuration

In Nano, use the following keyboard shortcuts:

  • Ctrl + O: Write the changes to the file.
  • Enter: Confirm the filename.
  • Ctrl + X: Exit Nano.

4. Update the Zsh initialization command

Open the Zsh configuration file: 

nano ~/.zshrc

Locate the existing Oh My Posh initialization command and replace it with: 

eval "$(oh-my-posh init zsh --config ~/mytheme.omp.json)"

Keep only one active Oh My Posh initialization command. If no initialization command exists, add the command above to ~/.zshrc.

Implementation Workflow

  1. Inspect the environment

    Confirm the Oh My Posh version and verify that Zsh is the active shell.

  2. Export the theme configuration

    Save the current configuration as ~/mytheme.omp.json.

  3. Back up the configuration

    Create a backup before making changes.

  4. Map the username

    Add the user_name mapping with the unicorn emoji.

  5. Configure the session segment

    Set the segment template to display {{ .UserName }}.

  6. Validate the JSON

    Run the Python JSON validation command to check the configuration syntax.

  7. Update Zsh

    Point the Oh My Posh initialization command in ~/.zshrc to the customized configuration.

  8. Reload the shell configuration

    Run source ~/.zshrc and inspect the resulting prompt.

Verification

After reloading Zsh, check whether the username portion of the prompt displays the unicorn emoji.

Expected prompt 
🦄 ~/Documents ❯

The working directory and prompt symbol should remain consistent with the selected theme.

If the username is still displayed, check that the mapping key matches the output of whoami, that the session segment uses the intended template, and that Zsh is loading the correct configuration file.

Troubleshooting

Problem Possible cause Suggested action
JSON validation fails Missing commas, quotation marks or braces. Review the JSON structure and validate again.
Username remains visible The mapping key does not match the actual username. Run whoami and update the mapping.
Unicorn does not appear Emoji rendering or font support may be unavailable. Check terminal emoji support and font settings.
Old prompt still appears Zsh may be loading a different configuration. Check the initialization command in ~/.zshrc.
Prompt configuration fails The edited theme may contain an invalid or misplaced segment. Review the JSON structure and segment placement.

Restore the backup

If the customization causes problems, restore the original configuration: 

cp ~/mytheme.omp.json.bak ~/mytheme.omp.json
source ~/.zshrc

Conclusion

This customization demonstrates how an Oh My Posh JSON configuration can be adjusted to change the username displayed in a macOS Zsh terminal prompt.

The approach uses a username mapping and a session segment template to display a unicorn emoji instead of the account username. The configuration is kept in a separate file, allowing the original theme to be preserved as a backup.

After validating the JSON and updating the Oh My Posh initialization command, the Zsh configuration can be reloaded to test the expected prompt appearance.
